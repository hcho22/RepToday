# Creative brief: A5-offline-forever

Status: draft.
This brief was generated by the dry-run creative loop.

## Pain state

Internet requirement is a dealbreaker; connectivity failures destroy progress mid-trip.
Verbatim source quote: "It doesn't need internet connection to fully operate (workouts)... So it stays offline (forever)."
Source: https://hn.algolia.com/api/v1/items/25727614

## Hypothesis

Offline-first demanders will respond to on-device generation shown with airplane mode on.

## Hook

A session is ready in under 100 milliseconds, offline.

## Format

10s screen-record video, airplane mode toggle then app open (tiktok)

## Pre-registered success signal

comment sentiment naming offline as the reason, plus above-median hold rate over 7 days

## Kill criterion

no offline-naming comments and below-median hold rate after 14 days

Screen images simulated. App is pre-release.
