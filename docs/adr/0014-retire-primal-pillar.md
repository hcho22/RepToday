# ADR-0014: Retire the primal pillar

- Status: Accepted (decided 2026-11-10); not yet implemented (M1, `US-TD01`).
- Date: 2026-11-10
- Deciders: captain, via the Push/Pull/Legs design grill (2026-11-09 to 2026-11-10)
- Spec: `.claude/agent/tasks/prd-ppl-rest-accounts-coach-agent_261110.md`
- Amends: [ADR-0001](0001-strength-primary-sessions.md) and US-E02 - primal is no longer a session pillar; strength-primary stands.
- Relates to: `CONTEXT.md` -> "Pillar".

## Context

Primal earns a dedicated block in 41-60 minute sessions.
For beginners and intermediates the only primal movements are crawls (Bear Crawl, Crab Walk) that need a clear strip of floor, which home and hotel-room users often lack, and the block adds one more movement to sessions users already find crowded.

## Decision

**Primal is retired as a training family.**
No session has a primal block, and every primal movement is withdrawn from sessions; logged history is kept and still decodes.
Bear Hold stays on the core ladder, so the Core Sprinkle still carries a ground-based hold.

## Consequences

- Sessions are warm-up + one group's main movements + Core Sprinkle + cooldown.
- Removing the block frees about 9-12 minutes in long sessions, absorbed by reps and rest under ADR-0013.
- Bear Crawl and Crab Walk leave the staple list (ADR-0007).
